# Research for the Library Journal Club (society layer)

Literature review and key papers for the hackathon idea: every paper in a Zotero library becomes an agent; the agents peer-review, dispute, collaborate and archive.

## Review (`review/`)
Read in this order:

1. [synthesis.md](review/synthesis.md) — what to borrow, corrections to the pitch doc, revised round, caps, interfaces, build order.
2. [organisation_diagram.md](review/organisation_diagram.md) — two figures: the nightly workflow (map, debate, directions) and the backtest (papers after T as the answer key, hit rate vs a no-discussion baseline).
3. [ascollab.md](review/ascollab.md) — anchor 1: "Hypothesis Hunting with Evolving Networks of Autonomous Scientific Agents" (Liu et al., Cambridge, arXiv 2510.08619). Flat society, registry + archive, K=2 blind review, tournament meta-review. No dispute mechanism.
4. [virtual_lab.md](review/virtual_lab.md) — anchor 2: The Virtual Lab (Swanson ... Zou, Nature 2025; bioRxiv, not arXiv). Four-field agents, PI + standing Critic, team/individual meetings, parallel-and-merge, structured summaries.
5. [organisation_structure.md](review/organisation_structure.md) — 30 papers on topology, roles, review, archives, disputes, human steering.
6. [rsi.md](review/rsi.md) — 27 papers on whether and how agent societies improve across rounds.

Method: `academic-deep-research` lit-review mode, four parallel agents (two deep reads, two WHY/HOW/WHAT sweeps), every arXiv ID fetched from its abs page. Gray-zone references were excluded. Unverified items are flagged inline.
